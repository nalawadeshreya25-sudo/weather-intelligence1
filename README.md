 Weather Intelligence & Forecasting Platform

A web-based weather dashboard that displays current weather conditions, hourly forecasts, 7-day forecasts, air quality, UV index, and experimental machine-learning temperature predictions.

## Live Demo

https://weather-intelligence-seven.vercel.app

## Features

- Current weather information
- Hourly and 7-day weather forecasts
- Weather charts and visualizations
- Air quality and UV index information
- Experimental temperature prediction using Linear Regression
- Responsive web interface

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Recharts
- Open-Meteo API
- Python
- scikit-learn
- Vercel

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open http://localhost:3000 in your browser.

## Machine Learning

The project includes an experimental Linear Regression model trained on synthetic sample data. Its prediction is for demonstration purposes and should not be considered an actual weather forecast.

## Data Source

Weather data is provided by Open-Meteo APIs.

## Deployment

Deployed using Vercel.
